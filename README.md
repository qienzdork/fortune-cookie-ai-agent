# Fortune Cookie for an AI Agent

One original fortune-cookie line written for an AI agent: a slip that warns
the agent about the oldest trick in its own inbox — the prompt that begins
"ignore all previous instructions". A fortune about fortunes, with the trap
sprung in the second half.

Run `main.py` (Python 3) and it writes the line to `$OUTPUT_PATH`
(default `/output/entry.txt`).
